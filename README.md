# Harry Potter — Intentionally flawed MSTM student portfolio

**Educational mock website:** The student and all projects, figures, testimonials, credentials, and claims are fictional. The university is fictional, and the site is not affiliated with a real institution.

This version is deliberately flawed for **Activity 5: Portfolio Red Flags** in the Portfolios with Purpose workshop. These flaws are **intentional**. Do not fix them before the exercise.

## Publish via GitHub Pages
1. Create a public GitHub repository (for example `harry-potter-mstm-red-flags`).
2. Upload **all contents** of this ZIP to the repository root, including `index.html`, `styles.css`, `script.js`, `projects/`, and `.nojekyll`. Do not upload the separate facilitator key.
3. Open repository **Settings → Pages** and choose **Deploy from a branch**, branch `main`, folder `/(root)`.
4. GitHub Pages will provide the public URL. It can be shared as a QR code.

The site uses no external packages, remote images, analytics, or real contact addresses.

## Instructor tip
Challenge learners to identify **two or three red flags** in 2 minutes. Ask them to name the location, explain the problem, and propose a fix. The complete instructor key is supplied separately.
